# Skill: аккуратный коммит
1. Выполни git status и git diff.
2. Проверь, что не попали .env, ключи, __pycache__/, .venv/. Если попали —
остановись и сообщи.
3. Разные задачи — разные коммиты. Добавляй файлы явно, а не git add .
вслепую.
4. Формат: <тип>(<область>): <что сделано>; типы feat, fix, docs, refactor,
test, chore; до 72 символов, с маленькой буквы, без точки.
5. После коммита покажи git log --oneline -5. Не делай push без просьбы.
